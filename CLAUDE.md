# Projekt
Es geht in dem Projekt darum, einen Prototyp für ein UX Projekt zu erstellen. Dazu einige grundlegende Infos: 

- Lox Fidelity - kein Styling, weiss, schwarz, grau, max eine Farbe - Fokus auf Flow nicht Look
- Nur für Text-Zwecke, Code muss nicht weiter verwertet werden, kein Anspruch an Architektur, Framework oder Testing
- Falls es Sinn macht, ein Framework oder Tests zu nutzen, ist dies jedoch nicht generell verboten, es hat nuir keine Prio.

# Schritte
Das Projekt ist in mehere Schritte unterteilt, diese sollen einzeln getestet und erstellt werden. Die Schritte liegen in @/docs/schritt-x.
