# Anpassung 1 - Picker Komponente
Verwandte Konzept-Annahme (KA): 1

Die Tests haben gezeigt, dass die User die Nutzung der Picker-Komponente nicht verstehen und die Tastaturbedinenung ein Muster ist, welches die User nicht nutzen. Aus diesem Grund soll der Picker iin Schritt 1 durch eine normale Fall-Weiche mit Auswahl ersetzt werden. 

## Anpassungen
Bitte entferne das Modal mit der Suche und den oben angezeigten Fällen.
Bitte mach den Button rechts die ganze grösse mit "Neu" und dem Chevorn nach unten.
Danch sollen unten die. Fälle wie bereits jetzt angezeigt werden. 
Beim mittleren Fall soll darunter klein eine Erklärung angezeigt werden "Erfassung von Mitgliedschaften von zwei Personen"
