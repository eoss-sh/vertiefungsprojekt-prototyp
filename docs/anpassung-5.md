# Anpassung 4 - Brief / Rechnung Vorschau
Verwandte Konzept-Annahme (KA): 5

Die Vorschau der Brief/Rechnungen und Mails soll genauer dargestellt werden, damit der User diese als Vorlagen erkennt und so besser sehen kann, dass diese angepasst werden können.

## Anpassungen 
- Vorschau mit echtem Text statt Platzhalter-Balken — die ersten Zeilen des tatsächlichen Briefs/Rechnung andeuten, damit es nach einem Dokument aussieht 
- Klickbare Karte statt versteckter Icons — die ganze Karte klickbar machen mit einem "Bearbeiten"-Link oder Button darunter, statt kleiner Icons in der Ecke        
- Visueller Dokument-Rahmen — Schatten + leicht abgesetzter "Papier"-Look (weiss auf grauem Hintergrund), damit es nach einem Blatt Papier aussieht
